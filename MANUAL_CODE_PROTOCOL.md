# MANUAL CODE PROTOCOL

This protocol ensures you learn by typing all code yourself while I provide explanations, meaning, and guidance.

## How It Works
1. **I explain** what code you need to write, why it's needed, and what each part means
2. **You type** the code yourself into the appropriate file in your project folder
3. **I verify** by asking you to show me the file or describe what you wrote
4. **We discuss** any errors, improvements, or alternative approaches
5. **I never write** the code for you - you build muscle memory by typing it yourself

## Files You'll Work With
- `src/index.html` - HTML structure
- `src/style.css` - Styling and layout  
- `src/script.js` - JavaScript functionality (when we get there)
- `server.js` - Node.js/Express backend (later lessons)
- Other files as we progress through lessons

## Process for Each Coding Step
1. I say: "In your [filename] file, add the following code:"
2. I explain: what the code does, line by line, in simple terms
3. I explain: why we need this code and how it connects to other parts
4. You type: the code yourself into the correct file
5. You tell me: "Done" or show me the file content
6. I respond: with confirmation, corrections, or next steps

## Benefits
- Builds typing proficiency and familiarity with syntax
- Reinforces learning through active creation (not passive copying)
- Helps you understand where code belongs in the project structure
- Creates muscle memory for common patterns
- Makes you self-reliant for future coding
